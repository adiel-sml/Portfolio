Ingénieur DevOps Optimum Tracker · Meyreuil

Contexte
Optimum Tracker, leader français du tracker solaire, conçoit des structures qui orientent les panneaux selon la course du soleil : O-Track pour les grandes centrales, Agri-Track pour l'agrivoltaïsme. Sur le terrain, les équipes pilotent et supervisent les centrales agrivoltaïques avec les applications mobiles TCU Control et AgriTrack. Dans la suite de mon alternance, j'ai repris la livraison et le RUN de la plateforme.
Besoin
Livrer les applications mobiles en continu sur les stores, mettre à jour des serveurs vieillissants sans interrompre la supervision des centrales, et réduire les incidents en production.
Solution

DevOps Déploiement continu sur l'App Store et Google Play avec Appcircle et Codemagic, gestion des certificats et des clés de signature. Montées de version par playbooks Ansible : Ubuntu 20.04 vers 22.04 et Node.js 16 vers 20, sans interruption de service. MCO : diagnostic (journalctl, systemctl, scripts Bash), recherche de la cause racine et support aux équipes terrain.

Développement Nouvelles fonctionnalités et correctifs des applications React Native, API Node.js pour le web et le mobile.

Agile Équipe en Agile Scrum : besoins priorisés avec les équipes terrain, livraisons itératives, revues de code et Git flow.

Résultat
  • −40 % d'incidents
  • Montées de version sans interruption
  • Livraisons continues sur les stores
  • Appcircle
  • Codemagic
  • Ansible
  • Ubuntu
  • Bash
  • App Store Connect
  • Play Console
  • React Native
  • Node.js
