Ingénieur DevOps Dooke Consulting · Paris, hybride · CDD

Contexte
Dooke Consulting est la division ingénierie du numérique de Dooke Corporation, présente en France et en Afrique. J'y ai travaillé sur une plateforme de gestion des interventions techniques pour des clients du transport en zones portuaires.
Besoin
Héberger et livrer de façon fiable l'API et la base de données de la plateforme, automatiser des déploiements encore manuels, et préparer l'infrastructure à monter en charge.
Solution

DevOps Serveurs d'API Node.js et de base de données conteneurisés avec Docker, derrière Nginx en reverse proxy, infrastructure cloud provisionnée en Terraform. Pipelines CI/CD GitHub Actions et GitLab CI : tests, build des images Docker et déploiement automatique à chaque push sur main. Supervision des services avec Prometheus. POC de migration de Docker vers Kubernetes : architecture cible et maquette de déploiement.

Développement API REST et application mobile React Native : gestion des interventions, inventaire des outils et tickets.

Agile Travail en Agile Scrum : priorisation du besoin, livraisons itératives, revues de code et Git flow.

Résultat
Une plateforme déployée automatiquement à chaque modification, une infrastructure décrite en code et reproductible, et une trajectoire de migration vers Kubernetes posée par un POC.

  • GitHub Actions
  • GitLab CI
  • Nginx
  • Prometheus

  • Node.js
