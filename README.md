# Portfolio d'Adiel Sanga

Site statique (HTML et CSS, sans étape de construction).

## Mettre en ligne sur Vercel

1. Sur vercel.com : **Add New**, puis **Project**, et importer le dépôt `portfolio`.
2. Framework : **Other**. Laisser la commande de construction vide et le dossier de sortie par défaut (la racine).
3. **Deploy**. Chaque push sur `main` met le site à jour.

## Modifier le contenu

Le texte est dans `index.html` (accueil), `a-propos.html`, `experiences.html` et `projets.html` ; les couleurs et la mise en page dans `style.css`, les vidéos dans `assets/videos/`. Réglages Vercel (cache des fichiers) : `vercel.json`.
