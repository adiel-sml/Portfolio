05/2026 à 10/2026

Ingénieur DevOps Dooke Consulting · Paris, hybride · CDD

Contexte
Dooke Consulting est la division ingénierie du numérique de Dooke Corporation, présente en France et en Afrique. J'y ai travaillé sur une plateforme de gestion des interventions techniques pour des clients du transport en zones portuaires.
Besoin
Héberger et livrer de façon fiable l'API et la base de données de la plateforme, automatiser des déploiements encore manuels, et préparer l'infrastructure à monter en charge.
Solution

DevOps Serveurs d'API Node.js et de base de données conteneurisés avec Docker, derrière Nginx en reverse proxy, infrastructure cloud provisionnée en Terraform. Pipelines CI/CD GitHub Actions et GitLab CI : tests, build des images Docker et déploiement automatique à chaque push sur main. Supervision des services avec Prometheus. POC de migration de Docker vers Kubernetes : architecture cible et maquette de déploiement.

Développement API REST et application mobile React Native : gestion des interventions, inventaire des outils et tickets.

Agile Travail en Agile Scrum : priorisation du besoin, livraisons itératives, revues de code et Git flow.

Résultat
Une plateforme déployée automatiquement à chaque modification, une infrastructure décrite en code et reproductible, et une trajectoire de migration vers Kubernetes posée par un POC.

Ingénieur DevOps Optimum Tracker · Meyreuil

Contexte
Optimum Tracker, leader français du tracker solaire, conçoit des structures qui orientent les panneaux selon la course du soleil : O-Track pour les grandes centrales, Agri-Track pour l'agrivoltaïsme. Sur le terrain, les équipes pilotent et supervisent les centrales agrivoltaïques avec les applications mobiles TCU Control et AgriTrack. Dans la suite de mon alternance, j'ai repris la livraison et le RUN de la plateforme.
Besoin
Livrer les applications mobiles en continu sur les stores, mettre à jour des serveurs vieillissants sans interrompre la supervision des centrales, et réduire les incidents en production.
Solution

DevOps Déploiement continu sur l'App Store et Google Play avec Appcircle et Codemagic, gestion des certificats et des clés de signature. Montées de version par playbooks Ansible : Ubuntu 20.04 vers 22.04 et Node.js 16 vers 20, sans interruption de service. MCO : diagnostic (journalctl, systemctl, scripts Bash), recherche de la cause racine et support aux équipes terrain.

Développement Nouvelles fonctionnalités et correctifs des applications React Native, API Node.js pour le web et le mobile.

Agile Équipe en Agile Scrum : besoins priorisés avec les équipes terrain, livraisons itératives, revues de code et Git flow.

Résultat

  • Montées de version sans interruption
  • Livraisons continues sur les stores

04/2024 à 09/2025

Ingénieur DevOps, stage puis alternance Optimum Tracker · Meyreuil

Contexte
Les trackers d'Optimum Tracker équipent des centrales solaires partout en France. Sur cette même plateforme de supervision, j'ai rejoint une équipe technique de deux personnes, en BUILD comme en RUN.
Besoin
Savoir en temps réel si les centrales sont disponibles, surveiller les serveurs et l'API, être alerté dès qu'un incident survient, et livrer sans casser la production.
Solution

DevOps Monitoring de la disponibilité des centrales : Grafana connecté à notre API, tableaux de bord et alertes. Métriques des serveurs (CPU, mémoire, disque) et temps de réponse de l'API. Intégration continue GitHub Actions avec tests Jest et E2E bloquants avant toute mise en production.

Développement Conception de la GMAO interne (React, Node.js, Express, MySQL) : tickets, planification, tableaux de bord, droits utilisateurs et écrans mobiles de suivi terrain.

Agile Méthodologie Agile Scrum en lien direct avec les équipes métier : recueil et priorisation des besoins, livraisons itératives, revues de code et Git flow.

Résultat
  • +50 % de réactivité opérationnelle
  • 50 % d'anomalies détectées avant la production
  • −60 % de temps de traitement des interventions
