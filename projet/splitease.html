SplitEase

Une application installable (PWA) pour partager les dépenses entre amis, en voyage ou en colocation.

  • Simplification des dettes par graphe : le moins de remboursements possible
  • Authentification, base PostgreSQL et synchronisation en temps réel avec Supabase
  • Mode hors ligne, export CSV, partage de groupe par lien
  • Mobile first, thème clair ou sombre, accessibilité WCAG AA
  • React 18
  • TypeScript
  • Supabase
  • PostgreSQL
  • Tailwind
  • PWA
