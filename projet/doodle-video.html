Doodle Video

Un plugin Claude Code (skills et outils) qui pilote un pipeline de production vidéo automatisé : moteur d'animation 2D en canvas, voix off synthétisée et alignée mot à mot, rendu headless, contrôles qualité automatiques (zones sûres, plans figés, transcription de la voix) et export multi formats. Un épisode par jour sur TikTok.

  • Claude Code
  • JavaScript
  • Python
  • Playwright
  • FFmpeg
  • Whisper
