GoWithMe

Une marketplace de colivraison entre l'Afrique et l'Europe : les voyageurs qui ont des kilos libres dans leur valise rencontrent ceux qui veulent envoyer un colis.

  • Application mobile React Native et Expo, monorepo partagé avec l'API et le back-office
  • API NestJS, PostgreSQL et Redis
  • Paiements séquestrés avec Stripe (Europe) et Flutterwave (Afrique)
  • Vérification d'identité (KYC), codes de remise et de livraison, suivi en temps réel
  • Environnements Docker Compose et CI/CD avec GitHub Actions
  • React Native
  • Expo
  • NestJS
  • PostgreSQL
  • Redis
  • Stripe
  • Docker
  • GitHub Actions
