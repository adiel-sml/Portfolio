Side projects

G

GoWithMe

Une marketplace de colivraison entre l'Afrique et l'Europe : les voyageurs qui ont des kilos libres dans leur valise rencontrent ceux qui veulent envoyer un colis.

  • Application mobile React Native et Expo, monorepo partagé avec l'API et le back-office
  • API NestJS, PostgreSQL et Redis
  • Paiements séquestrés avec Stripe (Europe) et Flutterwave (Afrique)
  • Vérification d'identité (KYC), codes de remise et de livraison, suivi en temps réel
  • Environnements Docker Compose et CI/CD avec GitHub Actions
  • React Native
  • Expo
  • NestJS
  • PostgreSQL
  • Redis
  • Stripe
  • Docker
  • GitHub Actions
S

SplitEase

Une application installable (PWA) pour partager les dépenses entre amis, en voyage ou en colocation.

  • Simplification des dettes par graphe : le moins de remboursements possible
  • Authentification, base PostgreSQL et synchronisation en temps réel avec Supabase
  • Mode hors ligne, export CSV, partage de groupe par lien
  • Mobile first, thème clair ou sombre, accessibilité WCAG AA
  • React 18
  • TypeScript
  • Supabase
  • PostgreSQL
  • Tailwind
  • PWA
