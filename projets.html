G

GoWithMe

Une marketplace de colivraison entre l'Afrique et l'Europe : les voyageurs qui ont des kilos libres dans leur valise rencontrent ceux qui veulent envoyer un colis.

  • Application mobile React Native et Expo, monorepo partagé avec l'API et le back-office
  • API NestJS, PostgreSQL et Redis
  • Paiements séquestrés avec Stripe (Europe) et Flutterwave (Afrique)
  • Vérification d'identité avec Didit, données de vols AeroDataBox, codes de remise et de livraison, suivi en temps réel
  • Environnements Docker Compose et CI/CD GitHub Actions : lint, tests, build
  • React Native
  • Expo
  • NestJS
  • PostgreSQL
  • Redis
  • Stripe
  • Docker
  • GitHub Actions

SplitEase

Une application installable (PWA) pour partager les dépenses entre amis, en voyage ou en colocation.

Lab DevOps

Mon laboratoire personnel : toute la chaîne IaC, Kubernetes et GitOps sur des VM locales. Les VM sont provisionnées en Terraform et configurées par des playbooks Ansible, les applications tournent sur un cluster kind et sont packagées en charts Helm, Argo CD synchronise le cluster sur le dépôt Git, et les pipelines tournent sur GitLab CI. C'est là que je teste avant de mettre en production.
